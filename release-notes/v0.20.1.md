## 中文

### 快速监测

- 总览现在优先显示“工作可用性”：可以继续使用、需要处理或需要刷新，并说明最需要关注的账户原因。
- Windows 托盘提示会同步显示账户健康状态、待处理事项与下一次自动同步倒计时。
- 自动同步计划会公开下一次执行时间；更改同步间隔后会按新设置重新计时。

### 同步可靠性

- 自动同步调度检查从最长 60 秒延迟缩短到 15 秒。
- 慢速远端请求不再推迟后续同步周期。
- 应用隐藏到托盘后会定期刷新本地状态，自动同步结果会及时反映在托盘和总览中。

### 工程质量

- 新增 GitHub Actions Windows 校验：前端检查、Rust 全目标检查和后端测试。
- 新增自动同步计划相关测试。

## English

### At-a-glance monitoring

- The overview now prioritizes work availability: ready to use, needs attention, or needs refresh, with the account requiring action called out clearly.
- The Windows tray tooltip now reflects account health, pending issues, and the countdown to the next automatic sync.
- The next automatic sync is exposed to the app, and changing the interval starts a new schedule.

### Sync reliability

- Automatic sync checks now run with up to a 15-second delay instead of up to 60 seconds.
- Slow remote requests no longer push every subsequent sync cycle later.
- When the window is hidden to the tray, local state refreshes regularly so automatic sync results reach both the tray and overview promptly.

### Engineering quality

- Added GitHub Actions verification on Windows for frontend checks, Rust target checks, and backend tests.
- Added coverage for automatic sync scheduling.
