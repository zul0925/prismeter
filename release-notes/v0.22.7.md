# Prismeter 0.22.7

## Startup data and language lifecycle fix

- Connected accounts and cached metrics now render immediately without requiring a manual sync or language change.
- Data refresh and sync no longer reinitialize or change the selected interface language.
- Following the system language now uses the native Windows user locale.
- Platform-specific rendering and desktop-preference failures are isolated so one failure cannot blank the whole application.
- Added startup architecture regression checks covering state initialization, rendering isolation, and language stability.
