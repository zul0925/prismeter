# Prismeter v0.21.5

## Dynamic language refresh repair

- Fixed the localization cache for reused DOM text nodes. Dynamic content now receives a fresh translation source whenever a sync, refresh, or view render changes the node text.
- Centralized toast, update-status, and metric-dialog text through the same localization gateway.
- This resolves the failure mode where the dictionary contained a translation but the live Overview continued to show the previous Chinese value.
