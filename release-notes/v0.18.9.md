## 中文

### 性能

- “全部同步”、定时同步和失败自动重试改为并发执行，每批最多同时同步 4 个账户。
- 多账户场景不再逐个等待远端响应；单个平台变慢时，不会阻塞同一批次中的其他账户。

### 可靠性

- 同步结果仍严格保持账户添加顺序，现有总览、活动记录和拖拽排序逻辑不受影响。
- 并发任务会独立记录成功、失败与耗时；单个任务异常终止时会返回可诊断错误，不影响其他账户完成同步。
- 新增跨批次顺序与失败历史回归测试。

---

## English

### Performance

- Sync all, scheduled sync, and automatic failure retries now run in parallel batches of up to four accounts.
- Multiple accounts no longer wait for every previous remote response; a slow provider does not block other accounts in the same batch.

### Reliability

- Results remain in account order, preserving the existing overview, activity history, and drag-and-drop ordering behavior.
- Each concurrent task records its own outcome and duration. An unexpected task failure produces a diagnosable result without blocking other accounts.
- Added regression coverage for ordering and failure history across multiple batches.
