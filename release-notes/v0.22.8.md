# Prismeter 0.22.8

## Definitive startup-state fix

- Restored the missing initial backend state that caused startup rendering to abort before account data was requested.
- Backend data loading now starts before non-critical placeholder rendering.
- Tauri desktop commands and native locale lookup can no longer block account loading or language persistence.
- Language-only settings changes no longer invoke unrelated desktop preference commands.
- Verified against a live WebView with four real connected accounts: all four render on first load, Chinese persists, and all four remain after state refresh.
