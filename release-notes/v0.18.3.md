## 中文

- 修复右上角关闭按钮因缺少 Tauri 窗口权限而无效的问题。
- 开启“关闭时隐藏到托盘”后，关闭按钮和 Alt+F4 会隐藏主窗口；关闭该设置后会退出应用。
- 窗口操作失败时会显示明确的错误提示。
- 新增窗口 API 权限的构建期回归检查。

## English

- Fixed the custom title-bar close button being blocked by a missing Tauri window permission.
- With “Close to tray” enabled, the close button and Alt+F4 hide the main window; otherwise they exit the app.
- Window action failures now show a visible error message.
- Added build-time regression checks for window API permissions.
