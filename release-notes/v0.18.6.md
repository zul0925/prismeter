## 中文

- 自动保留最近一次有效的本地状态备份，备份中的凭据仍使用 Windows DPAPI 加密。
- 主状态文件意外损坏时会自动恢复账户、设置和同步状态，并在应用内提示一次。
- 正常保存前会验证主文件，只使用有效状态更新恢复备份。
- 移除账户、清除历史或裁剪过期记录时会同步更新备份，避免已删除内容在恢复后重新出现。
- 新增备份轮换、损坏恢复和删除一致性测试。

## English

- Prismeter now keeps the latest valid local-state backup; credentials remain encrypted with Windows DPAPI in the backup.
- If the primary state file is damaged, accounts, settings, and sync state are restored automatically with a one-time in-app notice.
- The primary file is validated before it can replace the recovery backup.
- Account removal, history clearing, and retention pruning also update the backup so deleted data cannot reappear after recovery.
- Added regression coverage for backup rotation, corruption recovery, and deletion consistency.
