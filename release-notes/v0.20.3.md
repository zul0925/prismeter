## 中文

### 完整更新日志

- 签名构建现在自动使用 `release-notes/vX.Y.Z.md` 生成 Tauri 更新清单，不再使用固定的概括性文案。
- GitHub Release 和应用内更新弹窗从同一份正式发布说明获取内容，避免两个入口的更新日志不一致。

### 更新弹窗

- 应用内更新日志现在会展示发布说明中的标题、分段和列表，便于快速了解改动。
- 更新说明仍以纯文本安全转义后渲染，不执行发布说明中的 HTML 或脚本。

## English

### Complete update notes

- Signed builds now generate the Tauri update manifest from `release-notes/vX.Y.Z.md` instead of using a fixed generic summary.
- GitHub Releases and the in-app update dialog now use the same source of truth, preventing inconsistent change logs.

### Update dialog

- In-app update notes now render headings, sections, and lists from release notes for faster scanning.
- Release-note text is still safely escaped and does not execute HTML or scripts.
