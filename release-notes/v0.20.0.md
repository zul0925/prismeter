## 中文

### 账户级提醒

- OpenAI/Codex、火山方舟和 DeepSeek 账户新增独立提醒规则。
- 单个账户可以覆盖全局套餐额度、低余额和数据过期阈值；未设置的项目继续跟随全局规则。
- 可以只关闭某个账户在提醒中心与 Windows 通知中的提醒，不影响该账户继续同步。
- 修改账户规则后会重新评估提醒，并清理该账户旧规则留下的通知去重与暂缓状态。

### 交互修复

- 删除账户改用 Prismeter 应用内确认框，不再显示带有 `127.0.0.1` 标题的浏览器原生提示。
- 前端构建检查现在会禁止 `alert`、`confirm` 和 `prompt`，避免相同问题再次出现。
- 删除账户时明确说明：只会清理本机凭据与历史，平台侧账户和远端数据不受影响。

### 支持范围

- 本次新功能仅覆盖 OpenAI/Codex、火山方舟和 DeepSeek。
- Xiaomi MiMo 不纳入后续提醒能力开发；已有旧连接仅保留兼容读取。

## English

### Per-account alerts

- OpenAI/Codex, Volcengine Ark, and DeepSeek accounts now support individual alert rules.
- An account can override global quota, low-balance, and stale-data thresholds while unspecified values continue to inherit global settings.
- Alerts can be disabled for one account without pausing its synchronization.
- Updating a rule re-evaluates alerts and clears stale notification-deduplication and snooze state for that account.

### Interaction fixes

- Account removal now uses a Prismeter in-app confirmation instead of a browser-native dialog exposing the `127.0.0.1` loopback origin.
- Frontend validation now rejects `alert`, `confirm`, and `prompt` calls to prevent regressions.
- The removal dialog clearly explains that only local credentials and history are deleted; the remote platform account and data are unchanged.

### Support scope

- This release extends OpenAI/Codex, Volcengine Ark, and DeepSeek only.
- Xiaomi MiMo is excluded from future alert development; existing legacy connections remain readable for compatibility.
