## 中文

- 提醒中心新增单条“暂缓 24 小时”和“恢复提醒”。
- 暂缓只暂停对应的 Windows 通知，告警仍保留在界面中，真实状态和同步功能不受影响。
- 已暂缓提醒会显示恢复时间，并计入当前筛选结果摘要。
- 数据过期判断统一移至后端，现在可以触发 Windows 通知并使用同一套暂缓逻辑。
- 暂缓到期后会自动恢复通知资格；移除账户时会同步清理相关暂缓记录。

## English

- Added per-alert “Snooze for 24 hours” and “Resume alert” controls.
- Snoozing only pauses the corresponding Windows notification; the alert remains visible and synchronization is unaffected.
- Snoozed alerts show their resume time and are included in filter summaries.
- Stale-data detection now runs in the backend, enabling Windows notifications and the same snooze workflow.
- Notification eligibility returns automatically after expiry, and related snoozes are removed with an account.
