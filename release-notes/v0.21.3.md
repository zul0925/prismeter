# Prismeter v0.21.3

## English interface rendering fix

- Re-render all data-driven views whenever the interface language changes or a saved language preference is loaded.
- Moved Overview monitoring, account-count, sync schedule, Action Center, activity, and platform-card system copy into keyed language formatting.
- Normalized common platform-returned system labels such as monthly usage, cycle usage, remote sync, and sync timestamps before rendering.

## Important

- User-provided account names are intentionally not translated. They are account data rather than Prismeter interface copy.
