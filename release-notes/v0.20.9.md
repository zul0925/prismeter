# Prismeter v0.20.9

## Internationalization reliability

- Added a keyed Chinese/English message system for dynamic sync, freshness, retry, error, trend, and desktop-setting states.
- Interface language now also updates `title`, `aria-label`, and `placeholder` attributes, not only visible text nodes.
- Added a release check that verifies every keyed Chinese message has a non-empty English counterpart.

## Notes

- Provider names and remote data remain unchanged, as they are returned by their respective platforms.
