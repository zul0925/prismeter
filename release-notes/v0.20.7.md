## 中文

### 国际化基础与 English 界面

- 设置页新增“语言 / Language”，可在简体中文与 English 之间即时切换，并自动保存到本机设置。
- English 优先覆盖导航、账户连接、提醒、同步、更新和设置等高频操作区域。
- 日期和数字格式会随界面语言调整；平台原始模型名、远端数据和 API 返回字段保持原样，避免错误翻译。

### 可持续扩展

- 文案切换使用集中式词条机制，后续新增平台与功能可以补充同一份词条，不再复制两套页面结构。

## English

### Internationalization foundation and English UI

- Added a Language setting with immediate, persistent switching between Simplified Chinese and English.
- English now covers high-frequency areas including navigation, account connections, alerts, sync, updates, and settings.
- Date and number formatting follows the selected interface language. Provider model names, remote data, and API fields stay unchanged to avoid mistranslation.

### Sustainable expansion

- UI copy now uses a centralized translation mechanism, so future providers and features can extend the same vocabulary without duplicating page structures.
