## 中文

### Kimi API 余额监测

- 新增 Kimi API 账户连接，使用官方余额接口读取可用余额、代金券余额和现金余额。
- Kimi 账户现已接入自动同步、低余额提醒、Windows 通知、远端快照、趋势图和耗尽预估。
- Kimi API Key 继续仅使用本机 Windows DPAPI 加密保存，连接、修改凭据时均会先验证，失败不会覆盖已有连接。

### 多平台接入基础

- 新平台复用统一的账户、凭据、远端快照和提醒链路；后续添加有官方授权接口的平台时可保持同样的数据边界与监测体验。
- 能力矩阵明确标注 Kimi 当前可用的官方字段；模型与 Token 用量明细尚无可用接口时不会虚构数据。

## English

### Kimi API balance monitoring

- Added Kimi API accounts with the official balance endpoint for available, voucher, and cash balances.
- Kimi accounts now participate in automatic sync, low-balance alerts, Windows notifications, remote snapshots, trends, and exhaustion estimates.
- Kimi API keys remain encrypted locally with Windows DPAPI. New or updated credentials are validated before replacing an existing connection.

### Multi-provider foundation

- New providers reuse a consistent account, credential, remote-snapshot, and alert pipeline, preserving the same trustworthy data boundaries as Prismeter grows.
- The capability matrix explicitly lists the Kimi fields available today; no model or token usage is fabricated where an official endpoint is unavailable.
