# Prismeter v0.21.2

## Language switching reliability

- Fixed translation matching for HTML text nodes that include indentation or newlines, eliminating the partial English/Chinese rendering caused by whitespace-sensitive lookup.
- Extended the interface audit to validate the same whitespace-wrapped text shape used by rendered static HTML.
- Preserved Chinese as the source text when switching back from English.

## Ongoing work

- Dynamic status and provider copy are being moved from inline strings into keyed messages in the next internationalization pass; this release fixes the static rendering defect that caused mixed language in the main UI.
