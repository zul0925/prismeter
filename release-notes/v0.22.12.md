# Prismeter 0.22.12

## Interface consistency fixes

- Trend guidance now uses state-specific SVG icons: a flat chart for steady usage, a clock while collecting, an information mark for unsupported metrics, and an upward trend only for risk states.
- The main window now opens at a standard desktop size instead of maximized.
- Replaced font-dependent settings symbols with consistently aligned inline SVG icons.
- Removed inset strokes and nested focus outlines from text and number inputs in light and dark themes.
- Standardized every combobox with 13 px primary labels, 11 px descriptions, balanced columns, and wrapped long copy.
- Comboboxes now enable scrolling only when they contain more than five options and display five rows at a time.
- Replaced the heavy native-looking menu scrollbar with a narrow, theme-aware scrollbar.
- Removed remaining Chinese labels from English platform, overview, alert, account, and metric views.
