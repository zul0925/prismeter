# Prismeter v0.21.4

## Complete English rendering fallback

- Added a renderer-level Chinese-to-English fallback for legacy, dynamically assembled, and provider-returned system text.
- Applies complete phrases first and then longer interface fragments, including content inserted after an asynchronous sync.
- Works with the existing language observer, so live updates cannot bypass the selected English interface.

## Data handling

- Account names and remote model names are still treated as account data whenever they do not contain Prismeter system terminology.
