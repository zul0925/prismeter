# Prismeter 0.22.14

- Adds OpenRouter account connections using an API key.
- Reads remaining credits, the credit limit, and all-time usage from the official /key endpoint.
- Surfaces daily, weekly, and monthly spend alongside all-time usage on the OpenRouter card.
- Credits are shown in USD and join trend snapshots, low-balance alerts, and depletion forecasts.
- Unlimited keys report no remaining balance and are excluded from low-balance alerts.
- Per-model token history remains unavailable from the official API.
